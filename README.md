# Data Analysis Projects

A collection of data analysis and exploratory data analysis (EDA) projects, built using Python — primarily Pandas, NumPy, and Matplotlib.

## About

This repository contains hands-on data analysis projects, mostly developed and published on Kaggle, then documented here for portfolio purposes. Each project folder includes the notebook, visualizations, and a brief summary of findings.

## Projects

- **Netflix Content Analysis** — Exploratory analysis of Netflix's movies and TV shows dataset, covering content distribution, release trends, top countries, and genre popularity.

## Tools & Libraries

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook / Kaggle Notebooks
